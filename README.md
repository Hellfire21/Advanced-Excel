# Advanced-Excel🏠 
## Indian Property Sales & Dashboard Analysis — Excel

### 📊 Project Overview
An Excel-based Indian Property Sales Analysis project focused on exploring, cleaning, transforming, and analyzing property-related data to generate meaningful business insights.
The project demonstrates the use of Microsoft Excel for data analysis, formula management, data cleaning, sales performance classification, regional analysis, trend analysis, and dashboard development.
The workbook contains multiple analytical exercises covering the complete journey from raw property data to business-focused reporting.

###🎯 Project Objectives
Explore and understand Indian property data.
Calculate key revenue and business metrics.
Audit and manage Excel formulas.
Clean and structure property datasets.
Identify important business insights.
Classify sales performance.
Analyze sales performance region-wise.
Merge and retrieve relevant data.
Analyze sales trends.
Build an interactive property sales dashboard.

##📁 Project Structure
The workbook is organized into the following analysis sections:

###1. Exploring Property Sales Data
Explored the property dataset and its key attributes such as:
Property ID
Property Name
Builder Name
City
Region
Pincode
Property Type
Property Status
Number of Floors
Number of Apartments
Flat Types / BHK

###2. Calculating Revenue & Key Metrics
Performed calculations to derive important business and property-related metrics from the dataset.

###3. Auditing Formulas & Managing Data
Used Excel formula-auditing techniques to understand and validate calculations, including:

Trace Precedents
Trace Dependents
Formula management
Formula verification

###4. Cleaning & Structuring Data
Performed data-cleaning and restructuring activities to make the dataset suitable for analysis.

Key activities included:

Cleaning inconsistent data
Structuring columns
Updating city-related information
Preparing data for further analysis
5. Identifying Business Insights

Analyzed the property dataset to identify useful patterns and business insights.

### 6. Classifying Sales Performance
Created classifications to evaluate and categorize sales performance using Excel-based calculations.

### 7. Region-wise Sales Analysis
Analyzed property/sales performance across different regions to identify regional patterns and differences.

### 8. Merging & Retrieving Data
Used Excel data-retrieval and merging techniques to combine relevant information and retrieve required records.

### 9. Sales Trend Analysis
Analyzed sales trends to understand changes in property sales performance over time.

### 10. Dashboard
Created a consolidated dashboard to present the analyzed information in a visually understandable format.
